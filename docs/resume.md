# Resume-ready version

## Airline Reservation System
**Java, JSP, Servlets, JDBC, MySQL, HTML, CSS, JavaScript**

- Developed a full-stack airline reservation platform with user authentication, flight search, seat selection, reservation and cancellation workflows.
- Implemented JDBC DAO architecture with prepared statements and MySQL transactions to maintain booking consistency and prevent duplicate seat reservations.
- Built responsive JSP pages for flight search, booking, user reservations and administrator flight management.
- Containerized the application with Docker/Tomcat and configured environment-based database credentials for cloud deployment.
